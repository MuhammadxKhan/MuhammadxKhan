Portfolio research framework using market data, Monte Carlo simulation, fat-tailed scenario generation, bootstrap resampling, constrained optimisation, and VaR/CVaR analysis to study risk under different return assumptions.

### Computer Algebra System

### Macroeconomic Portfolio Simulation Engine

Object-oriented Python simulation modelling macro variables, crisis regimes, market shocks, transaction costs, leverage constraints, and portfolio risk management under changing market conditions.
